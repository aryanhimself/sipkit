# Changesets

This folder holds [changesets](https://github.com/changesets/changesets): one small Markdown file
per user-visible change to a published package (`sipkit-core`, `sipkit-react`, `sipkit-ui`,
`sipkit-engine-native`, `sipkit-noise`). Add one with `pnpm changeset`. The five packages are versioned
together (`fixed` in `config.json`). See [CONTRIBUTING.md](../CONTRIBUTING.md#releasing).
