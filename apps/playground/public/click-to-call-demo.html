Click-to-call demo

With the SipKit browser extension installed and "Call tel:, sip: and callto: links" switched on, these links dial on the extension's softphone (docs/browser-extension.md). Select a number and use the context menu, or type call 5550100 in the address bar.

  • +1 555 0100 (tel:)
  • 1002 (sip:)
  • 555 0199 (callto:)
  • Plain text: 98 4100 0000
